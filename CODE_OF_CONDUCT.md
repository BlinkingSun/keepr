# Code of Conduct

## The short version

Be decent. Assume the other person is trying to help. Criticise code, not people.

## What that means here

- Technical disagreement is welcome and useful. Personal remarks are not.
- Nobody owes you their time. Maintainers, reviewers and contributors are all doing
  this voluntarily.
- "This is wrong because X" is good. "This is obviously wrong" is not — say why.
- If you are new, ask. If someone is new, help.
- Harassment, discrimination, or making people feel unwelcome on the basis of who
  they are is not tolerated in issues, pull requests, or anywhere else this project
  operates.

## If something goes wrong

Report it by opening a private security advisory (it is the only private channel
this project has) or by contacting the maintainer through their GitHub profile.
Reports will be handled discreetly.

Consequences range from a request to change behaviour, to having contributions
declined, to being blocked from the repository. The maintainer decides, and will
explain the reasoning.
